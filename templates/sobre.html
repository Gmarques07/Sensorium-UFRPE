Sobre o Sensorium

O Sensorium transforma a complexidade dos dados de sensores em uma plataforma simples e visual. Em tempo real, você gerencia e entende o que está acontecendo em sua operação, permitindo ações rápidas e eficientes. Nossa arquitetura moderna garante que a solução cresça junto com o seu negócio.

Arquitetura e Tecnologias

Backend
  • FastAPI
  • SQLAlchemy
  • Pydantic
  • JSON Web Tokens (JWT)
Frontend
  • Jinja2
  • Bootstrap 5
  • Chart.js
Banco de Dados & DevOps
  • MySQL
  • Docker

  • Pytest
