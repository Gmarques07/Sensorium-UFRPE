Sensorium

Sobre o Sensorium

O Sensorium é uma plataforma web moderna para o gerenciamento e visualização de dados de sensores em tempo real, totalmente conteinerizada com Docker para garantir portabilidade e escalabilidade.

Nossa missão é transformar a maneira como interagimos com dados de IoT, oferecendo uma solução robusta, confiável e fácil de usar, validada por uma suíte de testes automatizados que garantem a integridade do sistema a cada implantação.

Arquitetura e Tecnologias

Backend
  • FastAPI
  • SQLAlchemy
  • Pydantic
  • JSON Web Tokens (JWT)
Frontend
  • Jinja2
  • Bootstrap 5
  • Chart.js
Banco de Dados & DevOps
  • MySQL
  • Docker
  • Docker Compose
  • Pytest
