# Documentação do Projeto Sensorium-UFRPE

## Estrutura de Documentação

Esta pasta contém toda a documentação do projeto organizada por categorias:

### 📁 `/arquitetura`
Documentos relacionados à arquitetura do sistema, design patterns e planejamento técnico.
- `REFATORACAO.md` - Plano de refatoração para evolução do sistema

### 📁 `/migracao`
Documentos relacionados à migração do sistema de Flask para FastAPI.
- `ATUALIZACAO_MIGRACAO.md` - Atualizações e melhorias implementadas na migração
- `MIGRACAO_FLASK_FASTAPI.md` - Documentação detalhada do processo de migração

### 📁 `/backend`
Documentos técnicos específicos do backend.
- `API.md` - Documentação da API
- `CONFIG.md` - Configurações do sistema
- `INSTALL.md` - Instruções de instalação
- `ALTERACAO_LOCAL.md` - Alterações relacionadas aos locais
- `TAREFAS_MIGRACAO.md` - Tarefas de migração
- `MIGRACAO.md` - Documentação de migração
- `README_INTEGRACAO.md` - Documentação de integração

### 📁 `/referencias`
Arquivos de referência e backup.
- `app.py.old` - Versão antiga do arquivo principal
- `main_original.py.bak` - Backup do arquivo main original
- `requeriments.txt OLD` - Versão antiga dos requirements

### 📁 `/utilitarios`
Scripts utilitários para desenvolvimento e testes.
- `check_deps.py` - Verificação de dependências
- `check_mysql.py` - Verificação de conexão com MySQL
- `test_api.py` - Testes da API

## Acesso à Documentação

- **Documentação principal do projeto**: `README.md` na raiz do projeto
- **Documentação do backend**: `backend/README.md`
- **Documentação da API**: Acessível via Swagger UI em `/api/docs` quando o servidor estiver rodando
